A especificação completa da Public API do TrucklineMP, apresentada de forma interativa com o Swagger UI. Cada endpoint, parâmetro e esquema de resposta é gerado em tempo real a partir da especificação OpenAPI em [trucklinemp.com/api/v1/openapi.json](https://trucklinemp.com/api/v1/openapi.json).

Use o filtro para encontrar um endpoint, expanda uma seção para ver parâmetros e exemplos, e clique em **Try it out** para enviar requisições reais. Os endpoints públicos de leitura funcionam sem chave de API; adicione uma chave `tlmp_api_...` a partir do [Console do Desenvolvedor](https://trucklinemp.com/developer) para aumentar seus limites de taxa.
