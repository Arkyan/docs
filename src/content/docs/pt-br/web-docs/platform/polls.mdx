As enquetes da comunidade permitem que a comunidade vote em questões sobre a plataforma, ideias para eventos e outros temas. Abra [trucklinemp.com/polls](https://trucklinemp.com/polls) para ver as enquetes abertas.

## Votar

Votar requer uma conta com sessão iniciada. Cada enquete mostra a sua pergunta, as opções, a hora de encerramento e se os resultados são públicos.

Algumas enquetes são restritas a apoiantes. As enquetes de apoiantes estão assinaladas na página da enquete.

## Resultados

Os resultados ficam disponíveis depois que a enquete termina, ou antes disso se a configuração permitir. A exibição dos resultados segue as opções definidas para cada enquete.
