O TrucklineMP publica o estado do serviço em tempo real e um changelog público das atualizações da plataforma. Ambos são públicos e não requerem conta.

## Estado do serviço

Abra [trucklinemp.com/status](https://trucklinemp.com/status) para ver o estado atual dos servidores e serviços da plataforma. A página reporta o estado em tempo real de cada serviço listado.

Se algo parecer estar fora do ar para todos, verifique a página de status antes de abrir um ticket de suporte.

## Changelog

Abra [trucklinemp.com/changelog](https://trucklinemp.com/changelog) para ler as notas de lançamento publicadas. Cada entrada mostra:

- A categoria (por exemplo, plataforma, comunidade ou eventos)
- A data de lançamento
- A versão, quando aplicável
- Um resumo do que mudou

As entradas são listadas das mais recentes para as mais antigas.
