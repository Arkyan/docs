O TrucklineMP gerencia programas da comunidade que reconhecem jogadores e empresas pelas suas contribuições. Estes incluem o programa Bug Hunters, o programa Contributors e os prêmios de Reconhecimento.

## Programas

Abra [trucklinemp.com/programs](https://trucklinemp.com/programs) para ver os programas ativos e os seus detalhes.

Cada página de programa explica o que é o programa, como participar e que reconhecimento está disponível.

## Bug Hunters

O programa Bug Hunters recompensa os jogadores que encontram e reportam bugs através do sistema de suporte. Os relatórios de bugs são revisados pela equipe e os bugs verificados recebem reconhecimento.

## Contributors

O programa Contributors reconhece as pessoas que contribuem para a plataforma ou para a sua documentação. Os contribuidores aparecem na página [Contribuidores](/pt-br/web-docs/contribute/contributors/) e podem receber selos.

## Reconhecimento

Os prêmios de Reconhecimento celebram contribuições notáveis para a comunidade. O reconhecimento é atribuído pela equipe e aparece no seu perfil público.
