Vincule o servidor do Discord da sua VTC ao TrucklineMP para exibi-lo no perfil público e aumentar a confiança de possíveis membros.

## Acessar às Configurações de Discord

1. Acesse o painel de gestão da sua VTC
2. Selecione **General Settings** na barra lateral
3. Role até a seção **Discord Server**

---

## Por que verificar o seu Discord?

- **Construir Confiança** - Mostra aos candidatos que o seu Discord é legítimo
- **Aumentar o engajamento** - Facilita aos membros encontrar o seu servidor
- **Aparência Profissional** - Exibido em destaque no perfil da sua VTC
- **Construção de Comunidade** - Liga as suas comunidades do TrucklineMP e do Discord

---

## Processo de Verificação

### Passo 1: Gerar Token
1. Clique em **Generate Verification Token**
2. É criado um token único para a sua VTC
3. O token é apresentado na tela
4. Copie o token usando o botão de copiar

### Passo 2: Convidar o Bot
1. Clique no link **Invite the TrucklineMP bot**
2. Selecione o seu servidor de Discord na lista
3. Conceda as permissões necessárias ao bot
4. Conclua o convite

**Permissões necessárias para o bot:**
- Ler Mensagens/Ver Canais
- Enviar Mensagens
- Usar Comandos de Barra

### Passo 3: Verificar o Servidor
1. Acesse qualquer canal do seu servidor de Discord
2. Digite o comando: `/verify-server <TOKEN>`
3. Substitua `<TOKEN>` pelo seu token real
4. O bot confirmará a verificação
5. O seu servidor agora está vinculado

### Passo 4: Confirmação
- Volte ao TrucklineMP
- A página detecta automaticamente a verificação
- Você verá uma notificação de sucesso
- O seu servidor de Discord é agora exibido no perfil da sua VTC

---

## Informação sobre o Token

### Expiração do Token
- Os tokens expiram após **15 minutos**
- Se o seu token expirar, gera um novo
- Cada VTC só pode ter um token ativo de cada vez

### Segurança do Token
- Os tokens são exclusivos da sua VTC
- Não compartilhe tokens publicamente
- Gere um novo token se este for comprometido

## Visibilidade do Servidor

Controle quem pode ver o seu servidor do Discord vinculado no perfil da sua VTC.

### Opções de Visibilidade

**Só Você**
- Só o proprietário da VTC pode ver o servidor de Discord
- Oculto dos membros e do público
- Útil durante a configuração ou se o servidor for privado

**Membros da VTC**
- Visível para todos os membros da sua VTC
- Oculto do público
- Bom para comunidades apenas para membros

**Todos**
- Visível no perfil público da sua VTC
- Qualquer pessoa pode ver o seu servidor de Discord
- Recomendado para recrutamento público

### Alterar a Visibilidade
1. Acesse a seção Servidor de Discord
2. Clique na opção de visibilidade pretendida
3. A alteração é salva automaticamente
4. Você verá uma notificação de sucesso

## Gerenciar o seu Servidor Ligado

### Ver o status do servidor
- Veja o nome do seu servidor vinculado
- Verifique o status da verificação (Verificado/Não verificado)
- Veja a configuração de visibilidade atual

### Gerar um Novo Token
- Clique em **Generate New Token**
- O token antigo é invalidado
- Use o novo token para reverificar se necessário

### Desvincular o servidor
1. Clique em **Unlink Server**
2. Confirme a ação
3. O seu servidor de Discord é removido do seu perfil
4. Você pode vincular outro servidor mais tarde

## Resolução de Problemas

### "O bot não responde ao meu comando"
- Garanta que o bot tem permissão para ler mensagens no canal
- Verifique se você está usando o token correto
- Verifique se o bot está no seu servidor
- Tente um canal diferente

### "O meu token expirou"
- Os tokens expiram após 15 minutos
- Gere um novo token
- Use o novo token imediatamente

### "A verificação não aparece no meu perfil"
- Atualize a página
- Verifique se a verificação foi concluída com sucesso
- Garanta que a visibilidade está definida como "Todos" ou "Membros da VTC"

### "Quero ligar um servidor diferente"
- Desliga primeiro o seu servidor atual
- Gere um novo token
- Siga o processo de verificação para o novo servidor

### "O bot não tem permissão"
- Acesse às configurações do seu servidor de Discord
- Acesse Cargos
- Garanta que o bot do TrucklineMP tem as permissões necessárias
- Tente o comando novamente

## Boas Práticas

### Configuração do Servidor
- Use um link de convite permanente
- Defina canais e regras claros
- Tem moderadores prontos para acolher novos membros
- Mantenha o seu servidor ativo e envolvente

### Visibilidade
- Defina a visibilidade como "Todos" para recrutamento público
- Use "Membros da VTC" para comunidades apenas para membros
- Use "Só Você" durante a configuração inicial

### Manutenção
- Verifique o seu servidor de Discord regularmente
- Responde prontamente às perguntas dos membros
- Mantenha o seu servidor organizado
- Atualize o perfil da sua VTC quando o Discord mudar

---

## Requisitos

Para verificar o seu servidor de Discord, você precisa de:
- Permissão **Gerenciar Servidor** no servidor de Discord
- **Permissões de gestão** na sua VTC no TrucklineMP
- Um servidor de Discord que cumpra as diretrizes do Discord
