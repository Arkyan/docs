A página Aparência no seu painel de gestão da empresa controla a aparência da sua página pública. Tem duas partes: o editor de tema e o construtor de layout inicial.

Abra **Appearance** na barra lateral (`/vtc/@handle/manage/appearance`). Requer a permissão `management.vtc.appearance`. Os proprietários têm sempre acesso.

## Editor de tema

O editor de tema define as cores de destaque, as cores de fundo e as cores de texto usadas em toda a página da sua empresa. As alterações são pré-visualizadas em tempo real antes de salvar.

As opções avançadas de tema estão bloqueadas para a maioria das empresas. Desbloqueiam-se para empresas com status Verificado e Parceiro em simultâneo.

As cores precisam passar verificações de contraste de legibilidade antes de poderem ser salvas, para que o texto se mantenha legível na página.

## Construtor de layout inicial

O construtor de layout inicial reorganiza as seções mostradas na página pública da sua empresa. Pode adicionar, mover, redimensionar ou remover seções como a visão geral, regras, membros, eventos, notícias, galeria ou recrutamento.

Este layout só está disponível para empresas com acesso a layout de página personalizado. Consulte o [Programa VTC Verificado](/pt-br/web-docs/vtc-programs/verified/) e o [Programa VTC Parceiro](/pt-br/web-docs/vtc-programs/partnered/) para os critérios de elegibilidade.
