The full TrucklineMP Public API specification, rendered interactively with Swagger UI. Every endpoint, parameter, and response schema is generated live from the OpenAPI spec at [trucklinemp.com/api/v1/openapi.json](https://trucklinemp.com/api/v1/openapi.json).

Use the filter to find an endpoint, expand a section to see parameters and examples, and press **Try it out** to send real requests. Public read endpoints work without an API key; add a `tlmp_api_...` key from the [Developer Console](https://trucklinemp.com/developer) to raise your rate limits.
