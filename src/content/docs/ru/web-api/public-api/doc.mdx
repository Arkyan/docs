Полная спецификация публичного API TrucklineMP, интерактивно отображаемая с помощью Swagger UI. Каждая конечная точка, параметр и схема ответа генерируются в реальном времени из спецификации OpenAPI по адресу [trucklinemp.com/api/v1/openapi.json](https://trucklinemp.com/api/v1/openapi.json).

Используйте фильтр, чтобы найти конечную точку, разверните раздел, чтобы увидеть параметры и примеры, и нажмите **Попробовать**, чтобы отправлять реальные запросы. Публичные конечные точки для чтения работают без ключа API; добавьте ключ `tlmp_api_...` из [Консоли разработчика](https://trucklinemp.com/developer), чтобы увеличить лимиты запросов.

## Дополнительные ресурсы
