TrucklineMP использует единую систему интернационализации, созданную на базе [Next-Intl](https://next-intl-docs.vercel.app/), для обработки многоязычной маршрутизации, каталогов переводов и вкладов в переводы.

---

## Каталоги переводов

Все переводимые строки в веб-приложении определены в файлах сообщений формата JSON, организованных по локалям в директории `messages/`:

```
messages/
├── en/                   # Английский (Исходный каталог)
│   ├── common.json
│   ├── account.json
│   └── ...
├── pl/                   # Польский
│   ├── common.json
│   └── ...
└── de/                   # Немецкий
    ├── common.json
    └── ...
```

### Форматирование сообщений
Ключи сообщений поддерживают стандартные функции перевода системы ICU, такие как интерполяция и множественные числа:
```json
{
  "welcome": "Welcome back, {username}!",
  "memberCount": "{count, plural, =0 {No members} =1 {1 member} other {# members}}"
}
```

## Рабочие пространства для переводов

TrucklineMP имеет встроенные рабочие пространства для управления и проверки переводов:

1. **Пользовательское рабочее пространство (`/translations`)**: Позволяет участникам сообщества отправлять варианты переводов для неполных ключей на выбранных ими языках.
2. **Рабочее пространство проверки (`/translations/[locale]/review`)**: Интерфейс рабочего процесса для модераторов переводов, позволяющий проверять, одобрять или отклонять предложенные переводы.
3. **Панель администратора переводов (`/admin/translations`)**: Интерфейс для системных администраторов, позволяющий настраивать поддерживаемые локали, управлять разрешениями пользовательских рабочих пространств и развертывать обновления каталога переводов.

## Инструменты командной строки для переводов

Доступно несколько скриптов командной строки для синхронизации, проверки и валидации каталогов переводов во время разработки.

### Синхронизация каталогов
Синхронизирует все каталоги целевых локалей (`messages/pl/*.json`, `messages/de/*.json` и так далее) со структурой исходного английского каталога, добавляя недостающие ключи и удаляя устаревшие ключи:
```bash
npm run i18n:sync
```

### Проверка каталогов
Проверяет, что все JSON файлы каталога правильно сформированы и содержат действительный синтаксис:
```bash
npm run i18n:check
```

### Проверка заполнителей макета
Проверяет, что переменные форматирования системы ICU (например, `{username}`) идеально совпадают в исходном английском файле и во всех переведенных файлах:
```bash
npm run i18n:layout
```

### Оценка покрытия
Вычисляет метрики процентного покрытия перевода для всех настроенных локалей:
```bash
npm run i18n:coverage
```

### Набор проверок
Запускает комплексные проверки валидации (проверка, строгое покрытие, проверки макета и модульные тесты в директории `src/i18n/__tests__/` для предотвращения проблем безопасности и атак с внедрением межсайтового скриптинга через переводы). Этот набор запускается конвейером непрерывной интеграции перед слиянием любых запросов на внесение изменений:
```bash
npm run i18n:verify
```
