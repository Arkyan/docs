Страница "Внешний вид" в панели управления вашей компанией управляет тем, как выглядит ваша публичная страница компании. Она состоит из двух частей: редактора темы и конструктора макета главной страницы.

Откройте раздел **Внешний вид** на боковой панели (`/vtc/@handle/manage/appearance`). Требуется разрешение `management.vtc.appearance`. Владельцы всегда имеют доступ.

## Редактор темы

Редактор темы устанавливает цвета акцентов, цвета фона и цвета текста, используемые на странице вашей компании. Изменения можно предварительно просмотреть в реальном времени перед их сохранением.

Расширенные параметры темы заблокированы для большинства компаний. Они разблокируются для компаний, имеющих статусы Верифицированной и Партнерской.

Цвета должны пройти проверку контрастности для удобочитаемости перед сохранением, чтобы текст оставался разборчивым на странице.

## Конструктор макета главной страницы

Конструктор макета главной страницы изменяет порядок разделов, отображаемых на вашей публичной странице компании. Вы можете добавлять, перемещать, изменять размер или удалять разделы, такие как обзор, правила, участники, мероприятия, новости, галерея или набор персонала.

Макет доступен только компаниям, имеющим доступ к пользовательскому макету страницы. См. [Программа верификации транспортных компаний](/ru/web-docs/vtc-programs/verified/) и [Партнерская программа транспортных компаний](/ru/web-docs/vtc-programs/partnered/) для ознакомления с требованиями.
