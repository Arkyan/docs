Вкладка Интеграции в панели управления вашей компании создает токены для встраивания, чтобы показывать ваши предстоящие мероприятия на внешнем сайте, например, на собственном сайте вашей транспортной компании или связанной странице сообщества.

Откройте **Управление**, затем **Интеграции** на боковой панели (`/vtc/@handle/manage/integrations`). Персонал с разрешением `events.manage` может создавать и отзывать токены.

## Как работает встраивание

Встраиваемый виджет это iframe, в котором отображается список ваших предстоящих мероприятий. Он загружается с TrucklineMP и обновляется автоматически по мере изменения мероприятий. Посетителям не нужен аккаунт для просмотра виджета.

## Создание токена для встраивания

1. Откройте **Интеграции**.
2. Нажмите **Создать токен**, дайте ему метку и сгенерируйте его.
3. Установите, сколько дней предстоящих мероприятий должен включать виджет.
4. Скопируйте сгенерированный фрагмент iframe и вставьте его на вашу внешнюю страницу.

## Отзыв токена

Токены могут быть отозваны в любое время на той же вкладке. Отзыв токена немедленно отключает все встраивания, которые его используют.

## Предварительный просмотр

Вкладка Интеграции показывает предварительный просмотр виджета в реальном времени по мере его настройки, поэтому вы можете проверить внешний вид перед копированием фрагмента.
