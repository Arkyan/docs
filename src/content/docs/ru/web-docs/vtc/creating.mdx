Виртуальная транспортная компания или виртуальная автобусная компания это дом вашей организации в TrucklineMP. Это руководство рассказывает о требованиях к кандидатам, мастере создания и о том, что происходит после запуска вашей компании.

## Перед началом

Вам потребуется:

- Авторизованный аккаунт TrucklineMP
- Разрешение на создание компании (применяются правила соответствия требованиям платформы)
- Отсутствие существующей компании того же типа, где вы уже являетесь владельцем (допускается владение одной транспортной и одной автобусной компанией на аккаунт)

Откройте процесс создания по адресу [trucklinemp.com/vtc/create](https://trucklinemp.com/vtc/create) для транспортных компаний, или [trucklinemp.com/vbc/create](https://trucklinemp.com/vbc/create) для автобусных компаний.

---

## Проверка соответствия требованиям

Когда вы открываете страницу создания, TrucklineMP автоматически запускает проверку соответствия требованиям. Если вы не соответствуете требованиям, страница объяснит причину. Общие причины включают:

- Вы уже являетесь владельцем компании запрашиваемого типа
- Репутация аккаунта или ограничения платформы (примечание: для создания компании нет требований к минимальному возрасту аккаунта)
- Функция отключена настройками платформы

Вы не сможете продолжить, пока не пройдете проверку соответствия требованиям.

## Мастер создания

Мастер состоит из пяти шагов: **Идентификация**, **Описание**, **Правила**, **Детали** и **Проверка**.

### Шаг 1: Идентификация

| Поле | Примечания |
|-------|-------|
| **Название компании** | Отображаемое имя, видимое на всей платформе. Обязательно. |
| **Идентификатор** | Уникальный URL-адрес: `trucklinemp.com/vtc/@yourhandle` (для транспортных компаний) или `trucklinemp.com/vbc/@yourhandle` (для автобусных компаний). От 2 до 15 символов, только строчные буквы, цифры и подчеркивания. Обязательно. |
| **Слоган** | Краткий девиз (необязательно). |
| **Основной язык** | Язык по умолчанию для вашей компании. |
| **Логотип** | URL-адрес HTTPS на квадратное изображение профиля (необязательно). |
| **Баннер** | URL-адрес HTTPS на широкое изображение обложки (необязательно). |
| **Видимость** | Общедоступный, доступный по ссылке или приватный режим. См. [Видимость](/ru/web-docs/vtc/visibility/). |

### Шаг 2: Описание

Напишите историю вашей компании в формате Markdown. Обязательное поле, до 5 000 символов. Этот текст будет отображаться в вашем общедоступном профиле.

### Шаг 3: Правила

Напишите правила для участников в формате Markdown. Обязательное поле, максимум 5 000 символов. Кандидаты и участники смогут ознакомиться с ними в вашем профиле.

### Шаг 4: Детали

| Поле | Примечания |
|-------|-------|
| **Минимальный возраст аккаунта** | Количество дней, которое должен существовать аккаунт TrucklineMP перед подачей заявки. Установите `0` для отсутствия ограничений. |
| **Минимальное время в игре** | Количество часов игрового времени, необходимое для подачи заявки. Установите `0` для отсутствия ограничений. |
| **Набор открыт** | Могут ли кандидаты подавать заявки сразу после создания. |
| **Контактный email** | Необязательный публичный контактный адрес электронной почты. |
| **Социальные сети** | Веб-сайт, приглашение Discord, Instagram, Facebook, X/Twitter. Если указаны, должны быть полными URL-адресами `https://`. |

### Шаг 5: Проверка

Подтвердите каждое поле, затем отправьте. В случае успеха вы будете перенаправлены в профиль вашей новой компании.

## Настройка по умолчанию

Когда ваша компания создана, TrucklineMP устанавливает базовые роли:

- **Руководство**
- **Персонал**
- **Водитель** (или **Водитель/Тренер** в зависимости от типа компании)
- **Рекрутер**

Вы становитесь владельцем с полными правами. Откройте **Управление** в профиле вашей компании, чтобы настроить набор персонала, участников и привязку Discord.

## Устранение неполадок

### "Не соответствует требованиям для создания компании"

Прочтите причины, указанные на странице создания. Возможно, вы уже являетесь владельцем компании этого типа или вам нужно решить проблему с репутацией аккаунта.

### Идентификатор не сохраняется

Идентификаторы должны содержать от 2 до 15 символов, быть в нижнем регистре и использовать только буквы, цифры и подчеркивания. Идентификатор должен быть уникальным.

### Ошибка создания из-за социальных URL-адресов

Каждый необязательный URL-адрес должен начинаться с `https://`. Ссылки-приглашения Discord должны быть полными URL-адресами, а не просто кодами.
