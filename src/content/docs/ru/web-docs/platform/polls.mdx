Опросы сообщества позволяют участникам голосовать по вопросам платформы, идеям для мероприятий и другим темам. Откройте [trucklinemp.com/polls](https://trucklinemp.com/polls), чтобы увидеть открытые опросы.

## Голосование

Для голосования требуется авторизованный аккаунт. В каждом опросе отображается вопрос, варианты ответов, время закрытия и информация о том, являются ли результаты публичными.

Некоторые опросы доступны только для спонсоров. Опросы для спонсоров имеют соответствующую отметку на странице опроса.

## Результаты

Результаты открываются после закрытия опроса или раньше, если это разрешено настройками опроса. Результаты опроса публикуются в соответствии с его настройками.
