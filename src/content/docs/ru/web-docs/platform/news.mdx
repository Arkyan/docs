TrucklineMP публикует официальные новости о платформе, мероприятиях и обновлениях сообщества. Новости общедоступны и не требуют наличия аккаунта для чтения.

## Чтение новостей

Откройте [trucklinemp.com/news](https://trucklinemp.com/news), чтобы просмотреть последние публикации. Публикации сгруппированы по таким категориям, как Основные, Платформа, Сообщество, Разработка или Мероприятия, и их можно отфильтровать в верхней части страницы.

## Отдельные публикации

Откройте любую публикацию, чтобы прочитать статью полностью. Публикации поддерживают расширенное форматирование, изображения и ссылки. Закрепленные публикации остаются в верхней части ленты до тех пор, пока их не открепят.

## Реакции

Авторизованные пользователи могут оставлять реакции на новостные публикации. Реакции это быстрый способ выразить поддержку или оставить отзыв к статье.

- [Публичный API](/ru/web-api/public-api/) - чтение новостей через API
