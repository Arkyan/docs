TrucklineMP включает отдельные каталоги для виртуальных транспортных компаний и виртуальных автобусных компаний, чтобы помочь водителям грузовиков и водителям автобусов находить организации. Просматривайте все публичные списки, фильтруйте по важным для вас параметрам и открывайте профиль компании, чтобы подать заявку или узнать больше.

## Доступ к каталогам

- **Каталог транспортных компаний**: Откройте [trucklinemp.com/vtc](https://trucklinemp.com/vtc).
- **Каталог автобусных компаний**: Откройте [trucklinemp.com/vbc](https://trucklinemp.com/vbc).

Здесь отображаются только **публичные** компании. Непубличные и приватные компании скрыты при просмотре каталога, если у вас нет прямой ссылки или приглашения.

---

## Поиск и фильтры

Используйте панель инструментов для сужения результатов:

| Фильтр | Назначение |
|--------|---------|
| **Поиск** | По названию, описанию или игровому тегу компании |
| **Проверенные** | Показать только проверенные компании |
| **Верифицированные** | Показать только верифицированные компании |
| **Официальные** | Показать официальные компании платформы |
| **Партнерские** | Показать только партнерские компании |
| **Набор открыт** | Компании, которые в данный момент принимают заявки |
| **Язык** | Фильтр основного языка |

### Параметры сортировки

- Сначала самые новые
- Наибольшее количество участников
- Наиболее активные
- По имени (A–Z)

Результаты обновляются при изменении фильтров. Пагинация загружает больше компаний, если они доступны.

## Карточки компаний

На каждой карточке отображается:

- Превью логотипа и баннера
- Название компании и идентификатор (`@handle`)
- Слоган или краткая выдержка из описания
- Значки (верифицирована, официальная, партнерская, набор открыт)
- Количество участников
- Основной язык

Нажмите на карточку, чтобы открыть полный профиль компании.

---

## Обзор профиля компании

Из профиля вы можете:

- Прочитать полное описание и правила
- Посмотреть предстоящие мероприятия и новости
- Посмотреть превью участников и открыть полный список
- Подать заявку, если набор открыт
- Присоединиться по приглашению, если у вас есть код
- Увидеть ссылку на верифицированный сервер Discord, если он настроен

В URL-адресах профилей используются идентификаторы: `trucklinemp.com/vtc/@handle` (для транспортных компаний) или `trucklinemp.com/vbc/@handle` (для автобусных компаний).

## Для владельцев компаний

Чтобы улучшить видимость:

1. Установите видимость на **публичную** в [Общих настройках](/ru/guides/vtc/general-settings/)
2. Держите набор открытым, если вы ищете сотрудников
3. Подайте заявку на статус [Верифицированной](/ru/guides/vtc-programs/verified/) или [Партнерской](/ru/guides/vtc-programs/partnered/), если соответствуете требованиям
4. Публикуйте [новости](/ru/guides/vtc/news/) и [мероприятия](/ru/guides/vtc/events/), чтобы ваш профиль оставался активным

Непубличные компании доступны по прямой ссылке, но не отображаются в результатах поиска каталога.

---

## Доступ к API

Сторонние инструменты могут выводить список компаний через публичный API:

```
GET https://api.trucklinemp.com/vtcs
```

См. [Публичный API](/ru/guides/developers/public-api/) для получения информации об аутентификации и пагинации.
