A especificação completa da Public API da TrucklineMP, apresentada de forma interativa com o Swagger UI. Cada endpoint, parâmetro e esquema de resposta é gerado ao vivo a partir da especificação OpenAPI em [trucklinemp.com/api/v1/openapi.json](https://trucklinemp.com/api/v1/openapi.json).

Usa o filtro para encontrar um endpoint, expande uma secção para ver parâmetros e exemplos, e clica em **Try it out** para enviar pedidos reais. Os endpoints públicos de leitura funcionam sem chave de API; adiciona uma chave `tlmp_api_...` a partir da [Consola de Programador](https://trucklinemp.com/developer) para aumentar os teus limites de taxa.
