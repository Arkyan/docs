A TrucklineMP oferece uma plataforma de programador para integrações de terceiros. Podes ler dados públicos da plataforma através da **Public API**, identificar utilizadores com **OAuth 2.0**, e receber atualizações em tempo real através de **webhooks**.

Esta documentação cobre conceitos e fluxos de trabalho. Para a lista completa de endpoints, formatos de pedido e esquemas de resposta, usa a referência interativa da API no site principal.

## O que podes construir

| Integração | Ideal para |
|-------------|----------|
| **Public API** | Bots, dashboards, sites de estatísticas e ferramentas que leem VTCs, eventos, notícias, utilizadores e dados de moderação |
| **Aplicações OAuth** | Aplicações que autenticam utilizadores com a sua conta TrucklineMP e leem dados de perfil com âmbito limitado |
| **Webhooks** | Serviços que reagem a eventos da plataforma (adesões de membros, banimentos, RSVPs, e mais) |

## Antes de começares

1. Cria uma conta TrucklineMP em [trucklinemp.com](https://trucklinemp.com).
2. Ativa o **Modo de Programador** em **Definições da Conta → Segurança → Modo de Programador → Ativar**.
3. Abre a [Consola de Programador](https://trucklinemp.com/developer) a partir da barra de navegação ou das tuas definições de segurança.

O Modo de Programador desbloqueia a consola. Não concede, por si só, permissões elevadas de API. Os endpoints da Public API mantêm-se apenas de leitura. Os âmbitos OAuth controlam a que dados de utilizador a tua aplicação pode aceder depois de um utilizador a autorizar.

## Início rápido: Public API

1. Na Consola de Programador, cria um **projeto**.
2. Gera uma chave de API (prefixo `tlmp_api_...`). Copia-a quando for mostrada. Não pode voltar a ser vista.
3. Envia um pedido com a tua chave:

```bash
curl -H "Authorization: Bearer tlmp_api_YOUR_API_KEY" \
  "https://api.trucklinemp.com/vtcs"
```

4. Experimenta os endpoints de forma interativa no [API Playground](https://trucklinemp.com/developer/playground).

Os endpoints públicos de leitura funcionam **sem** chave de API. As chaves aumentam os teus limites de taxa e associam a utilização ao teu projeto para análises.

## Início rápido: Aplicação OAuth

1. Na Consola de Programador, vai a **Aplicações OAuth** e cria uma aplicação.
2. Define os **URIs de redirecionamento** e os **âmbitos** na página de definições OAuth.
3. Copia a **ligação de instalação** da visão geral da aplicação (ou constrói o teu próprio URL de autorização).
4. Enquanto a aplicação não estiver publicada, adiciona **utilizadores de teste** para que outros a possam autorizar durante o desenvolvimento.
5. Quando estiver pronta, completa a verificação de domínio e publica através da página de Publicação.

Ver [OAuth Apps](/pt/web-api/oauth-apps/) para o fluxo de autorização completo, PKCE e regras de publicação.

## Privacidade e conformidade

A utilização da API é registada para limitação de taxa, prevenção de abuso e análises. Ver a [Política de Privacidade](https://id.trucklinemp.com/legal/privacy) para saber como a telemetria é tratada.

As Aplicações OAuth têm de fornecer um **URL de política de privacidade** e devem fornecer um **URL de termos de serviço** antes da publicação.
