A página Aparência no teu painel de gestão da empresa controla o aspeto da tua página pública. Tem duas partes: o editor de tema e o construtor de layout inicial.

Abre **Aparência** na barra lateral (`/vtc/@handle/manage/appearance`). Requer a permissão `management.vtc.appearance`. Os proprietários têm sempre acesso.

## Editor de tema

O editor de tema define as cores de destaque, as cores de fundo e as cores de texto usadas em toda a página da tua empresa. As alterações são pré-visualizadas em tempo real antes de guardares.

As opções avançadas de tema estão bloqueadas para a maioria das empresas. Desbloqueiam-se para empresas com estatuto Verificado e Parceiro em simultâneo.

As cores têm de passar verificações de contraste de legibilidade antes de poderem ser guardadas, para que o texto se mantenha legível na página.

## Construtor de layout inicial

O construtor de layout inicial reorganiza as secções mostradas na página pública da tua empresa. Podes adicionar, mover, redimensionar ou remover secções como a visão geral, regras, membros, eventos, notícias, galeria ou recrutamento.

Este layout só está disponível para empresas com acesso a layout de página personalizado. Consulta o [Programa VTC Verificado](/pt/web-docs/vtc-programs/verified/) e o [Programa VTC Parceiro](/pt/web-docs/vtc-programs/partnered/) para os critérios de elegibilidade.
