Liga o servidor de Discord da tua VTC à TrucklineMP para o mostrares no teu perfil público e construíres confiança junto de potenciais membros.

## Aceder às Definições de Discord

1. Navega até ao painel de gestão da tua VTC
2. Seleciona **Definições Gerais** na barra lateral
3. Desce até à secção **Servidor de Discord**

---

## Porquê Verificar o teu Discord?

- **Construir Confiança** - Mostra aos candidatos que o teu Discord é legítimo
- **Aumentar o Envolvimento** - Facilita aos membros encontrar o teu servidor
- **Aparência Profissional** - Exibido em destaque no perfil da tua VTC
- **Construção de Comunidade** - Liga as tuas comunidades da TrucklineMP e do Discord

---

## Processo de Verificação

### Passo 1: Gerar Token
1. Clica em **Gerar Token de Verificação**
2. É criado um token único para a tua VTC
3. O token é apresentado no ecrã
4. Copia o token usando o botão de copiar

### Passo 2: Convidar o Bot
1. Clica no link **Convidar o bot da TrucklineMP**
2. Seleciona o teu servidor de Discord na lista
3. Concede as permissões necessárias ao bot
4. Conclui o convite

**Permissões de Bot Necessárias:**
- Ler Mensagens/Ver Canais
- Enviar Mensagens
- Usar Comandos de Barra

### Passo 3: Verificar o Servidor
1. Vai a qualquer canal do teu servidor de Discord
2. Escreve o comando: `/verify-server <TOKEN>`
3. Substitui `<TOKEN>` pelo teu token real
4. O bot confirmará a verificação
5. O teu servidor está agora ligado

### Passo 4: Confirmação
- Regressa à TrucklineMP
- A página deteta automaticamente a verificação
- Verás uma notificação de sucesso
- O teu servidor de Discord é agora exibido no perfil da tua VTC

---

## Informação sobre o Token

### Expiração do Token
- Os tokens expiram após **15 minutos**
- Se o teu token expirar, gera um novo
- Cada VTC só pode ter um token ativo de cada vez

### Segurança do Token
- Os tokens são exclusivos da tua VTC
- Não partilhes tokens publicamente
- Gera um novo token se este for comprometido

---

## Visibilidade do Servidor

Controla quem pode ver o teu servidor de Discord ligado no perfil da tua VTC.

### Opções de Visibilidade

**Só Tu**
- Só o proprietário da VTC pode ver o servidor de Discord
- Oculto dos membros e do público
- Útil durante a configuração ou se o servidor for privado

**Membros da VTC**
- Visível para todos os membros da tua VTC
- Oculto do público
- Bom para comunidades apenas para membros

**Todos**
- Visível no perfil público da tua VTC
- Qualquer pessoa pode ver o teu servidor de Discord
- Recomendado para recrutamento público

### Alterar a Visibilidade
1. Vai à secção Servidor de Discord
2. Clica na opção de visibilidade pretendida
3. A alteração é guardada automaticamente
4. Verás uma notificação de sucesso

## Gerir o teu Servidor Ligado

### Ver o Estado do Servidor
- Vê o nome do teu servidor ligado
- Verifica o estado de verificação (Verificado/Não verificado)
- Vê a definição de visibilidade atual

### Gerar um Novo Token
- Clica em **Gerar Novo Token**
- O token antigo é invalidado
- Usa o novo token para reverificar se necessário

### Desligar o teu Servidor
1. Clica em **Desligar Servidor**
2. Confirma a ação
3. O teu servidor de Discord é removido do teu perfil
4. Podes ligar um servidor diferente mais tarde

## Resolução de Problemas

### "O bot não responde ao meu comando"
- Garante que o bot tem permissão para ler mensagens no canal
- Verifica se estás a usar o token correto
- Verifica se o bot está no teu servidor
- Tenta um canal diferente

### "O meu token expirou"
- Os tokens expiram após 15 minutos
- Gera um novo token
- Usa o novo token de imediato

### "A verificação não aparece no meu perfil"
- Atualiza a página
- Verifica se a verificação foi concluída com sucesso
- Garante que a visibilidade está definida como "Todos" ou "Membros da VTC"

### "Quero ligar um servidor diferente"
- Desliga primeiro o teu servidor atual
- Gera um novo token
- Segue o processo de verificação para o novo servidor

### "O bot não tem permissão"
- Vai às definições do teu servidor de Discord
- Navega até Cargos
- Garante que o bot da TrucklineMP tem as permissões necessárias
- Tenta o comando novamente

---

## Boas Práticas

### Configuração do Servidor
- Usa um link de convite permanente
- Define canais e regras claros
- Tem moderadores prontos para acolher novos membros
- Mantém o teu servidor ativo e envolvente

### Visibilidade
- Define a visibilidade como "Todos" para recrutamento público
- Usa "Membros da VTC" para comunidades apenas para membros
- Usa "Só Tu" durante a configuração inicial

### Manutenção
- Verifica o teu servidor de Discord regularmente
- Responde prontamente às perguntas dos membros
- Mantém o teu servidor organizado
- Atualiza o perfil da tua VTC quando o Discord mudar

---

## Requisitos

Para verificares o teu servidor de Discord, precisas de:
- Permissão **Gerir Servidor** no servidor de Discord
- **Permissões de gestão** na tua VTC na TrucklineMP
- Um servidor de Discord que cumpra as diretrizes do Discord
