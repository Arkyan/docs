O separador de Integrações no painel de gestão da tua empresa cria tokens de incorporação para mostrares os teus próximos eventos num site externo, como o site da tua VTC ou uma página da comunidade associada.

Abre **Manage** e depois **Integrations** na barra lateral (`/vtc/@handle/manage/integrations`). Os membros da equipa com a permissão `events.manage` podem criar e revogar tokens.

## Como funcionam as incorporações

Uma incorporação é um widget iframe que lista os teus próximos eventos. É servido a partir do TrucklineMP e atualiza-se automaticamente à medida que os eventos mudam. Os visitantes não precisam de conta para ver o widget.

## Criar um token de incorporação

1. Abre **Integrations**.
2. Clica em **Create Token**, dá-lhe um nome e gera-o.
3. Define quantos dias de próximos eventos o widget deve incluir.
4. Copia o excerto de iframe gerado e cola-o na tua página externa.

## Revogar um token

Os tokens podem ser revogados a qualquer momento a partir do mesmo separador. Revogar um token desativa imediatamente todas as incorporações que o utilizam.

## Pré-visualização

O separador de Integrações mostra uma pré-visualização em direto do widget enquanto o configuras, para poderes verificar o aspeto antes de copiar o excerto.
