Personaliza o aspeto do TrucklineMP e gere as preferências da tua conta.

## Aceder às Definições de Aparência

1. Clica no teu avatar no canto superior direito
2. Seleciona **Definições**
3. Seleciona o separador **Aparência**
4. Ou navega para `trucklinemp.com/user/me/settings?tab=appearance`

---

## Temas

Escolhe o aspeto do TrucklineMP. A tua preferência de tema é guardada automaticamente.

### Temas Disponíveis

#### Escuro
- A estética Marathon predefinida
- Fundos escuros com um estilo nítido e industrial
- Texto de alto contraste
- Confortável em ambientes com pouca luz

#### Claro
- Fundos brancos limpos
- Alto contraste para ambientes bem iluminados
- Aparência profissional
- Fácil de ler em salas bem iluminadas

#### Awfully Familiar Grey
- Cinzento escuro com detalhes verdes
- Uma estética única que parece estranhamente familiar
- Contraste médio
- Um equilíbrio entre os temas escuro e claro

### Selecionar um Tema
1. Percorre os cartões de tema
2. Cada cartão mostra uma amostra de pré-visualização com as cores do tema
3. Clica num tema para o aplicar
4. A alteração é instantânea e guardada automaticamente
5. Um pequeno indicador aparece no tema ativo

## Visita Guiada de Introdução

Se quiseres repetir a visita guiada ou o tutorial da plataforma, podes reiniciar a visita guiada a qualquer momento.

### Reiniciar a Visita
1. Desce até à secção **Introdução** do separador de definições de Aparência.
2. Clica no botão **Reiniciar visita guiada**.
3. Isto reinicia o estado da tua visita e reinicia imediatamente a sequência de introdução interativa guiada pelo John Driver.

## Aplicações Autorizadas

Gere aplicações de terceiros que têm acesso à tua conta.

### Aceder a Aplicações Autorizadas
1. Vai a **Definições** > separador **Aplicações Autorizadas**
2. Ou navega para `trucklinemp.com/user/me/settings?tab=authorized-apps`

### O que São Aplicações Autorizadas?
Aplicações de terceiros às quais concedeste acesso à tua conta TrucklineMP através de OAuth. Estas podem incluir:
- Configuradores de camiões
- Ferramentas de gestão de eventos
- Bots da comunidade
- Painéis de análise

### Rever Aplicações
Para cada aplicação autorizada, podes ver:
- **Nome da aplicação** – O nome da aplicação de terceiros
- **Permissões concedidas** – O que a aplicação pode aceder
- **Data de autorização** – Quando concedeste o acesso

### Revogar Acesso
1. Encontra a aplicação que queres revogar
2. Clica em **Revogar**
3. O acesso da aplicação é removido imediatamente
4. A aplicação terá de ser autorizada novamente se quiseres voltar a usá-la

### Quando Revogar
- Já não utilizas a aplicação
- Suspeitas de acesso não autorizado
- A aplicação foi comprometida
- Estás a limpar ligações antigas

## Exportação de Dados

Pede uma cópia dos teus dados armazenados pelo TrucklineMP.

### Aceder à Exportação de Dados
1. Vai a **Definições** > separador **Exportação de Dados**
2. Ou navega para `trucklinemp.com/user/me/settings?tab=export`

### O que está Incluído
A tua exportação inclui:
- Informações do perfil (nome, handle, imagem, links sociais)
- Histórico de participação em VTCs
- Registos de atividade
- Dados de configuração
- Publicações e tópicos do fórum
- Registos de participação em eventos

### Como Pedir
1. Clica em **Pedir Exportação**
2. A tua exportação é colocada em fila para processamento
3. Vais receber um email quando estiver pronta
4. Descarrega o ficheiro de dados a partir do link no email
5. O link de descarregamento expira ao fim de um período limitado

### Formato dos Dados
- As exportações são fornecidas em formato JSON
- Todos os dados são legíveis por máquina
- Podes importá-los para outras ferramentas ou guardá-los para os teus registos

## Definições do Fórum

Configura as tuas preferências do fórum.

### Aceder às Definições do Fórum
1. Vai a **Definições** > separador **Fórum**
2. Ou navega para `trucklinemp.com/user/me/settings?tab=forum`

### Definições Disponíveis
- **Preferências de notificação** – Controla como recebes notificações do fórum
- **Opções de visualização** – Personaliza como o conteúdo do fórum é apresentado
- **Definições de assinatura** – Define uma assinatura para as tuas publicações no fórum

## Boas Práticas

### Temas
- Escolhe um tema que funcione nas tuas condições de iluminação habituais
- Os temas escuros são melhores para sessões noturnas
- Os temas claros são melhores para uso diurno

### Aplicações Autorizadas
- Revê periodicamente as aplicações autorizadas
- Revoga aplicações que já não utilizas
- Autoriza apenas aplicações em que confies
- Verifica cuidadosamente as permissões antes de autorizar

### Exportação de Dados
- Pede uma exportação antes de eliminares a tua conta
- Guarda cópias de segurança dos teus dados
- Revê os teus dados para perceberes o que está armazenado

## Resolução de Problemas

### "O tema não está a mudar"
- Atualiza a página
- Limpa a cache do teu navegador
- Experimenta um navegador diferente

### "Não consigo revogar uma aplicação"
- Garante que tens uma ligação à internet estável
- Atualiza a página e tenta novamente
- Contacta o suporte se o problema persistir

### "A minha exportação de dados não chegou"
- Verifica a pasta de spam do teu email
- As exportações podem demorar alguns minutos a processar
- Contacta o suporte se demorar mais de uma hora
