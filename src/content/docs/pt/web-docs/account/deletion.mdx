Aprende como eliminar permanentemente a tua conta TrucklineMP e que dados são removidos.

## Aceder à Eliminação da Conta

1. Clica no teu avatar no canto superior direito
2. Seleciona **Definições**
3. Seleciona o separador **Perigo**
4. Ou navega para `trucklinemp.com/user/me/settings?tab=danger`

---

## Antes de Eliminares

### Considera Estas Alternativas
- **Faz uma pausa** - Podes simplesmente parar de usar o TrucklineMP sem eliminar a conta
- **Exporta os teus dados** - Pede uma exportação de dados antes de eliminar
- **Desliga contas** - Remove ligações se planeias voltar a registar-te

### Avisos Importantes
- **Esta ação é permanente e irreversível**
- Todos os teus dados serão removidos permanentemente
- Não podes recuperar a tua conta depois da eliminação
- O teu nome de utilizador e handle podem ficar disponíveis para outros usarem
- Se a autenticação de dois fatores estiver ativada, terás de introduzir um código de verificação ou de recuperação para confirmar a eliminação

---

## O que É Eliminado

### Removido Permanentemente
- O teu perfil (nome, handle, imagem, links sociais)
- Todas as adesões e cargos em VTCs
- O teu histórico de atividade
- Publicações e tópicos do fórum
- Registos de participação em eventos
- Dados de configuração
- Notas da equipa sobre ti
- Dados de sessão
- Informação de contas ligadas

### O que Pode Permanecer
- Alguns dados anonimizados podem ser retidos para fins analíticos
- Registos legais podem ser mantidos conforme exigido por lei

---

## Como Eliminar a Tua Conta

### Passo 1: Iniciar a Eliminação
1. Vai a **Definições** > separador **Perigo**
2. Clica em **Eliminar Conta**
3. Aparece uma janela de confirmação

### Passo 2: Aguardar o Tempo de Espera
- Inicia-se uma contagem decrescente de 5 segundos
- Isto evita eliminações acidentais
- Não podes avançar até a contagem terminar

### Passo 3: Confirmar a Eliminação
1. Escreve `DELETE` na caixa de confirmação
2. O botão de eliminar fica ativo depois do tempo de espera
3. Se tiveres a 2FA ativada, será pedido o teu código de autenticador ou de recuperação
4. Clica em **Eliminar a Minha Conta**

### Passo 4: Conclusão
- A tua conta é eliminada imediatamente
- A tua sessão é terminada
- És redirecionado para a página inicial
- Uma notificação de sucesso confirma a eliminação

---

## Depois da Eliminação

### O que Acontece
- A tua sessão é terminada em todos os dispositivos
- A página do teu perfil devolve um erro 404
- As tuas adesões a VTCs são removidas
- As tuas publicações e tópicos do fórum são removidos juntamente com o resto dos teus dados

### Posso Voltar a Registar-me?
- Sim, podes criar uma nova conta com o mesmo email
- Os teus dados antigos não serão restaurados
- O teu nome de utilizador e handle podem ficar disponíveis
- A propriedade de VTCs não pode ser recuperada

---

## Antes de Eliminar: Lista de Verificação

- [ ] Pedir uma exportação de dados
- [ ] Guardar informação importante
- [ ] Anotar os teus códigos de recuperação (se a 2FA estiver ativada)
- [ ] Desligar contas externas (opcional)
- [ ] Cancelar subscrição de emails

## Alternativas à Eliminação

### Se Estás Frustrado
- Contacta o suporte via Discord para resolver problemas
- Faz uma pausa na plataforma
- Ajusta as tuas definições de privacidade

### Se Queres um Recomeço
- Muda o teu nome de exibição e handle
- Atualiza a tua imagem de perfil
- Limpa a tua atividade saindo de VTCs
- Exporta primeiro os teus dados

### Se Estás Preocupado com Privacidade
- Oculta configurações externas
- Alterna a visibilidade do YouTube/Twitch
- Revê e revoga aplicações autorizadas
- Desliga ligações não utilizadas

---

## Resolução de Problemas

### "Não consigo eliminar a minha conta"
- Garante que escreveste `DELETE` exatamente
- Aguarda que o tempo de espera de 5 segundos termine
- Se tiveres a 2FA ativada, garante que introduziste um código de autenticador ou de recuperação válido

### "Eliminei a minha conta e quero-a de volta"
- A eliminação da conta é permanente e não pode ser revertida
- Podes criar uma nova conta
- Contacta o suporte se achares que a eliminação foi um erro
