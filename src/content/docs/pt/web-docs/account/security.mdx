Gere a segurança da tua conta, as sessões ativas e as definições de privacidade para manter a tua conta protegida.

## Aceder às Definições de Segurança

1. Clica no teu avatar no canto superior direito
2. Seleciona **Definições**
3. Seleciona o separador **Segurança**
4. Ou navega até `trucklinemp.com/user/me/settings?tab=security`

---

## Conta Ligada (Steam)

A tua conta Steam está permanentemente associada à tua conta do TrucklineMP.

- **Estado:** Não pode ser desligada
- **Finalidade:** Verificação de identidade principal
- **Steam ID:** Apresentado nesta secção

Esta ligação é necessária para a verificação da conta e não pode ser alterada.

## Autenticação de Dois Fatores (2FA)

Adiciona uma camada extra de segurança à tua conta.

### Ativar a 2FA

1. Clica em **Ativar 2FA**
2. É gerado um código QR
3. Lê o código QR com a tua aplicação de autenticação:
   - Google Authenticator
   - Authy
   - Microsoft Authenticator
   - Qualquer aplicação compatível com TOTP
4. Ou introduz manualmente a chave secreta mostrada por baixo do código QR
5. Clica em **Continuar para Verificação**
6. Introduz o código de 6 dígitos da tua aplicação
7. Clica em **Verificar e Ativar**
8. **Guarda os teus códigos de recuperação** - não voltam a ser mostrados

### Códigos de Recuperação

Quando ativas a 2FA, recebes **10 códigos de recuperação**:
- Cada código pode ser usado **uma vez**
- Usa-os se perderes o acesso à tua aplicação de autenticação
- Guarda-os num local seguro (gestor de palavras-passe, cópia impressa)
- Podes copiar todos os códigos de uma só vez

### Desativar a 2FA

1. Clica em **Desativar 2FA**
2. Introduz o código da tua aplicação de autenticação **ou** um código de recuperação
3. Clica em **Desativar 2FA**
4. A 2FA é removida da tua conta

**Aviso:** Desativar a 2FA torna a tua conta menos segura.

### Se Perderes a Tua Aplicação de Autenticação

1. Usa um código de recuperação para iniciar sessão
2. Depois de iniciares sessão, vai às Definições de Segurança
3. Desativa a 2FA usando o código de recuperação
4. Volta a ativar a 2FA com uma nova aplicação de autenticação

**Sem códigos de recuperação:** Contacta o suporte através do Discord com prova de identidade.

## Modo de Programador

Ativa a Consola de Programador para aceder a ferramentas profissionais.

### O Que Obténs
- Criar projetos de API
- Gerir credenciais de API
- Aceder à documentação para programadores
- Construir integrações com o TrucklineMP

### Ativar o Modo de Programador
1. Clica em **Ativar** na secção Modo de Programador
2. Lê a caixa de diálogo de confirmação
3. Clica em **Confirmar Ativação**
4. O modo de programador fica ativo

**Aviso:** Esta ação é permanente e irreversível.

### Aceder à Consola
- Depois de ativado, clica em **Abrir Consola** para aceder às ferramentas de programador
- Ou navega até `trucklinemp.com/developer`

## Sessões Ativas

Vê e gere todos os dispositivos com sessão iniciada na tua conta.

### Informação da Sessão
Cada sessão mostra:
- **Browser** - Chrome, Firefox, Safari, Edge
- **Sistema Operativo** - Windows, macOS, Linux, Android, iOS
- **Endereço IP** - O IP a partir do qual a sessão foi criada
- **Data de Início** - Quando a sessão foi criada
- **Etiqueta Atual** - Assinala a tua sessão atual

### Revogar uma Sessão
1. Encontra a sessão que queres revogar
2. Clica em **Revogar** ao lado dela
3. A sessão é terminada imediatamente
4. O dispositivo terá de iniciar sessão novamente

### Terminar Todas as Outras Sessões
1. Clica em **Terminar todas as outras sessões** no topo
2. Todas as sessões, exceto a atual, são revogadas
3. Útil se suspeitas de acesso não autorizado

## Definições de Privacidade

### Ocultar Configurações Externas
- Quando ativada, as tuas configurações do Truckline Utils só são visíveis para ti e para os administradores
- Os outros utilizadores não conseguem ver as tuas configurações no teu perfil
- Marca ou desmarca a caixa de verificação para ativar ou desativar

## Boas Práticas de Segurança

### Essencial
- **Ativa a 2FA** - O passo de segurança mais importante de todos
- **Guarda os códigos de recuperação** - Guarda-os num gestor de palavras-passe
- **Revê as sessões regularmente** - Revoga tudo o que não reconheças
- **Usa uma palavra-passe forte** - Exclusiva para o TrucklineMP

### Recomendado
- Termina a sessão em dispositivos partilhados
- Revê periodicamente as aplicações autorizadas
- Mantém as tuas contas ligadas atualizadas
- Reporta imediatamente qualquer atividade suspeita

## Resolução de problemas

### "Não consigo ativar a 2FA"
- Garante que a tua aplicação de autenticação suporta TOTP
- Verifica se a hora do teu dispositivo está sincronizada
- Experimenta outra aplicação de autenticação

### "Perdi os meus códigos de recuperação"
- Se ainda tens sessão iniciada, desativa a 2FA e volta a ativá-la
- Se ficaste sem acesso, contacta o suporte através do Discord
- Fornece prova de identidade para a recuperação da conta

### "Vejo uma sessão que não reconheço"
- Revoga a sessão imediatamente
- Altera a tua palavra-passe, se possível
- Ativa a 2FA, se ainda não estiver ativada
- Contacta o suporte se suspeitas de acesso não autorizado

### "Não consigo iniciar sessão com a 2FA"
- Verifica se a hora da tua aplicação de autenticação está correta
- Experimenta um código de recuperação
- Se nada resultar, contacta o suporte
