A TrucklineMP gere programas comunitários que reconhecem jogadores e empresas pelas suas contribuições. Estes incluem o programa Bug Hunters, o programa Contributors e os prémios de Reconhecimento.

## Programas

Abre [trucklinemp.com/programs](https://trucklinemp.com/programs) para veres os programas ativos e os seus detalhes.

Cada página de programa explica o que é o programa, como participar e que reconhecimento está disponível.

## Bug Hunters

O programa Bug Hunters recompensa os jogadores que encontram e reportam bugs através do sistema de suporte. Os relatórios de bugs são revistos pela equipa e os bugs verificados recebem reconhecimento.

## Contributors

O programa Contributors reconhece as pessoas que contribuem para a plataforma ou para a sua documentação. Os contribuidores aparecem na página [Contribuidores](/pt/web-docs/contribute/contributors/) e podem receber distintivos.

## Reconhecimento

Os prémios de Reconhecimento celebram contribuições notáveis para a comunidade. O reconhecimento é atribuído pela equipa e aparece no teu perfil público.
