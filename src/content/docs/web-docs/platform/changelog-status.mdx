TrucklineMP publishes live service status and a public changelog of platform updates. Both are public and do not require an account.

## Service status

Open [trucklinemp.com/status](https://trucklinemp.com/status) to see the current status of the platform's servers and services. The page reports live status for each listed service.

If something feels down for everyone, check the status page before opening a support ticket.

## Changelog

Open [trucklinemp.com/changelog](https://trucklinemp.com/changelog) to read published release notes. Each entry shows:

- The category (for example platform, community, or events)
- The release date
- The version, when one applies
- A summary of what changed

Entries are listed newest first.
