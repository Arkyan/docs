The gallery is your company's media library on TrucklineMP. It stores images, videos, and video links such as YouTube or Vimeo. Media you publish here appears in the gallery tab on your public company profile.

## Accessing the gallery

Open your company Manage panel and select **Gallery** from the sidebar (`/vtc/@handle/manage/gallery`).

You need the `gallery.manage` permission to manage media and albums. The `gallery.upload` permission lets a role add media without full management access. Owners always have full access.

## Albums

Albums group related media so visitors can browse by topic, for example recruitment, events, or history.

- Create albums from the gallery sidebar
- Assign media to an album when you add or edit it
- Visitors can filter the public gallery by album

## Adding media

1. Click **Add media**.
2. Paste one approved media link per line. Supported types are image URLs, direct video URLs, YouTube links, and Vimeo links.
3. Media publishes immediately unless hidden by moderation.

Uploaded files are compressed automatically. File uploads accept JPEG, PNG, or WebP.

## Managing media

From the gallery manager you can:

- Search media by title
- Filter by media type (image, video, YouTube, Vimeo)
- Edit titles, captions, and alt text
- Move media between albums
- Feature a piece of media so it stands out on the public gallery
- Publish or hide media
- Delete media

Media moderation follows the platform content rules. Inappropriate media can be hidden by staff.

## Public gallery

The gallery tab on your public company profile shows published media grouped by album. Featured media appears first. Visitors do not need an account to browse the gallery.
