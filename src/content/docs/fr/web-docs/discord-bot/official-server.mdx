TrucklineMP gère une **communauté Discord officielle** distincte des serveurs détenus par les VTC. Le serveur officiel utilise une pile de bots différente du **bot TrucklineMP** public utilisé pour les serveurs VTC et les Rôles liés.

Rejoignez-le via l'invitation liée depuis [trucklinemp.com](https://trucklinemp.com) ou la découverte Discord.

---

## Deux bots, deux rôles

| Bot | Où | Rôle |
|-----|-------|------|
| **Bot TrucklineMP** (DiscordBot) | Serveurs VTC et publics | Rôles liés, `/profile`, `/verify-server`, DM de notification, `/vtc` VTC |
| **Modbot** | Serveur principal officiel, staff et bêta | Modération, tickets, intégration du recrutement, journalisation |

Ne vous attendez pas à `/verify-server` sur le serveur officiel pour votre VTC. Effectuez la vérification sur **votre** Discord de VTC.

---

## Support du site vs tickets Discord

| Besoin | Où aller |
|------|-------------|
| Appels de bannissement | [trucklinemp.com/support?lane=appeal](/fr/web-docs/account/bans-appeals/) |
| Problèmes de compte | [Tickets de support](/fr/web-docs/account/support-tickets/) sur le site |
| Signalements de joueurs (plateforme) | Support du site ou signalement de profil |
| Modération de chat propre à Discord | Panneaux de tickets du serveur officiel (dans Discord) |

Modbot peut vous rediriger vers le site pour les appels. **Les appels via le site font foi** pour les bannissements de plateforme.

---

## Recrutement et intégration du staff

Le recrutement du staff passe par le Discord officiel une fois une candidature acceptée sur le portail de recrutement. Les étapes peuvent inclure :

- Rejoindre le serveur principal
- La vérification du NDA bêta sur le site
- L'attribution de rôle via une intégration automatisée

Les candidats doivent suivre précisément les instructions données en DM et dans les canaux.

---

## Rôles liés sur le serveur officiel

Le serveur officiel peut utiliser les Rôles liés TrucklineMP pour les membres vérifiés ou le staff. La configuration est la même que pour n'importe quel serveur : [Rôles liés](/fr/web-docs/discord-bot/linked-roles/).

---

## Les serveurs VTC sont indépendants

Les serveurs Discord de VTC sont gérés par les propriétaires de VTC. Le staff de TrucklineMP ne modère pas les serveurs VTC, sauf si une violation des règles de la plateforme est signalée via le [support](/fr/web-docs/account/support-tickets/).

Liez le serveur de votre VTC sur le site avec la [Vérification Discord VTC](/fr/web-docs/vtc/discord-verification/).
