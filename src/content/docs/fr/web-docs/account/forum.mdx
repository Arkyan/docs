Le forum TrucklineMP est un site communautaire distinct pour les discussions, les guides et les échanges organisés en sujets. Il est construit sur sa propre base de code et partage votre compte TrucklineMP via une authentification unique (SSO).

Le forum est actuellement en cours de déploiement progressif. La navigation principale du site l'affiche comme « à venir » pendant qu'il est préparé pour une disponibilité générale.

## URL du forum

Rendez-vous sur [forum.trucklinemp.com](https://forum.trucklinemp.com).

Connectez-vous avec le même compte que celui utilisé sur le site principal. Votre identité sur le forum utilise le nom de profil, l'identifiant et l'avatar de votre compte TrucklineMP.

---

## Liaison de compte

Aucune inscription supplémentaire n'est requise lorsque le SSO est activé. Si on vous demande de vous connecter :

1. Connectez-vous d'abord sur trucklinemp.com
2. Retournez sur le forum et choisissez **Sign in with TrucklineMP** (ou équivalent)
3. Approuvez la session

Vos messages sur le forum apparaissent dans l'onglet **Forum** de votre [profil public](/fr/web-docs/account/public-profile/) lorsque ce module est actif.

---

## Paramètres du forum

Configurez vos préférences sur le site principal :

1. Ouvrez **Settings**
2. Allez dans l'onglet **Forum** (`/user/me/settings?tab=forum`)

Les options incluent généralement :

- Les préférences de notification pour les réponses et mentions
- Les préférences d'affichage pour le rendu des sujets
- Le texte de signature ajouté à vos messages

Les paramètres de thème plus généraux se trouvent dans [Apparence et préférences](/fr/web-docs/account/appearance-preferences/).

---

## Notifications

Les notifications du forum peuvent apparaître :

- Dans l'interface de notification propre au forum
- Dans la [cloche de notification](/fr/web-docs/account/notifications/) de votre compte TrucklineMP lorsqu'elles sont relayées
- Par e-mail (si vous activez les notifications par e-mail sur le forum)

Vérifiez les deux sites si vous attendez une réponse.

---

## Modération

La modération du forum suit les [règles](https://id.trucklinemp.com/legal/rules) de TrucklineMP ainsi que des politiques propres au forum. Les infractions graves peuvent affecter votre réputation sur la plateforme principale, pas seulement votre accès au forum.

Signalez les messages à l'aide des outils de signalement du forum. Les appels concernant les bans à l'échelle de la plateforme passent toujours par le [Support](/fr/web-docs/account/support-tickets/).

---

## Export des données

Votre [export de données](/fr/web-docs/account/appearance-preferences/#export-des-données) sur le site principal peut inclure les messages et sujets du forum associés à votre compte.
