Découvrez comment supprimer définitivement votre compte TrucklineMP et quelles données sont supprimées.

## Accéder à la suppression du compte

1. Cliquez sur votre avatar dans le coin supérieur droit
2. Sélectionnez **Settings**
3. Sélectionnez l'onglet **Danger**
4. Ou accédez directement à `trucklinemp.com/user/me/settings?tab=danger`

---

## Avant de supprimer

### Envisagez ces alternatives
- **Faites une pause** - Vous pouvez simplement arrêter d'utiliser TrucklineMP sans supprimer votre compte
- **Exportez vos données** - Demandez un export de vos données avant de supprimer
- **Déconnectez vos comptes** - Supprimez les connexions si vous prévoyez de vous réinscrire

### Avertissements importants
- **Cette action est permanente et irréversible**
- Toutes vos données seront définitivement supprimées
- Vous ne pouvez pas récupérer votre compte après la suppression
- Votre nom d'utilisateur et votre identifiant pourront être utilisés par d'autres personnes
- Si l'authentification à deux facteurs est activée, vous devrez saisir un code de vérification ou de secours pour confirmer la suppression

---

## Ce qui est supprimé

### Définitivement supprimé
- Votre profil (nom, identifiant, photo, liens sociaux)
- Toutes vos adhésions et rôles au sein de VTC
- Votre historique d'activité
- Les messages et sujets du forum
- Les enregistrements de participation aux événements
- Les données de configuration
- Les notes de l'équipe vous concernant
- Les données de session
- Les informations de comptes connectés

### Ce qui peut rester
- Certaines données anonymisées peuvent être conservées à des fins d'analyse
- Des registres légaux peuvent être conservés comme l'exige la loi

---

## Comment supprimer votre compte

### Étape 1 : Lancer la suppression
1. Allez dans **Settings** > onglet **Danger**
2. Cliquez sur **Delete Account**
3. Une fenêtre de confirmation apparaît

### Étape 2 : Attendre le délai de sécurité
- Un compte à rebours de 5 secondes démarre
- Cela empêche les suppressions accidentelles
- Vous ne pouvez pas continuer tant que le compte à rebours n'est pas terminé

### Étape 3 : Confirmer la suppression
1. Tapez `DELETE` dans le champ de confirmation
2. Le bouton de suppression devient actif après le délai de sécurité
3. Si vous avez activé la 2FA, on vous demandera votre code d'authentification ou votre code de secours
4. Cliquez sur **Delete My Account**

### Étape 4 : Finalisation
- Votre compte est immédiatement supprimé
- Vous êtes déconnecté
- Vous êtes redirigé vers la page d'accueil
- Une notification de succès confirme la suppression

---

## Après la suppression

### Ce qui se passe
- Vous êtes déconnecté de toutes les sessions
- Votre page de profil renvoie une erreur 404
- Vos adhésions à des VTC sont supprimées
- Vos messages et sujets du forum sont supprimés avec le reste de vos données

### Puis-je me réinscrire ?
- Oui, vous pouvez créer un nouveau compte avec la même adresse e-mail
- Vos anciennes données ne seront pas restaurées
- Votre nom d'utilisateur et votre identifiant pourront être disponibles
- La propriété d'un VTC ne peut pas être récupérée

---

## Avant de supprimer : liste de vérification

- [ ] Demander un export de vos données
- [ ] Sauvegarder toute information importante
- [ ] Noter vos codes de secours (si la 2FA est activée)
- [ ] Déconnecter les comptes externes (facultatif)
- [ ] Se désabonner des e-mails

## Alternatives à la suppression

### Si vous êtes frustré
- Contactez le support via Discord pour résoudre les problèmes
- Faites une pause de la plateforme
- Ajustez vos paramètres de confidentialité

### Si vous voulez repartir de zéro
- Changez votre nom affiché et votre identifiant
- Mettez à jour votre photo de profil
- Effacez votre activité en quittant les VTC
- Exportez d'abord vos données

### Si vous vous inquiétez de votre confidentialité
- Masquez les configurations externes
- Basculez la visibilité de YouTube/Twitch
- Vérifiez et révoquez les applications autorisées
- Déconnectez les connexions inutilisées

---

## Dépannage

### « Je n'arrive pas à supprimer mon compte »
- Assurez-vous d'avoir tapé `DELETE` exactement
- Attendez la fin du délai de sécurité de 5 secondes
- Si vous avez activé la 2FA, assurez-vous d'avoir saisi un code d'authentification ou de secours valide

### « J'ai supprimé mon compte et je le veux de retour »
- La suppression de compte est permanente et ne peut pas être annulée
- Vous pouvez créer un nouveau compte
- Contactez le support si vous pensez que la suppression était une erreur
