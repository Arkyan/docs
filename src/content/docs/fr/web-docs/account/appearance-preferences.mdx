Personnalisez l'apparence de TrucklineMP et gérez les préférences de votre compte.

## Accéder aux paramètres d'apparence

1. Cliquez sur votre avatar dans le coin supérieur droit
2. Sélectionnez **Settings**
3. Sélectionnez l'onglet **Appearance**
4. Ou accédez directement à `trucklinemp.com/user/me/settings?tab=appearance`

---

## Thèmes

Choisissez l'apparence de TrucklineMP. Votre préférence de thème est enregistrée automatiquement.

### Thèmes disponibles

#### Dark
- L'esthétique Marathon par défaut
- Arrière-plans sombres avec un style industriel et tranché
- Texte à fort contraste
- Reposant pour les yeux dans les environnements peu éclairés

#### Light
- Arrière-plans blancs et épurés
- Fort contraste pour les environnements lumineux
- Apparence professionnelle
- Facile à lire dans les pièces bien éclairées

#### Awfully Familiar Grey
- Gris foncé avec des accents verts
- Une esthétique unique qui semble étrangement familière
- Contraste moyen
- Un équilibre entre les thèmes sombres et clairs

### Sélectionner un thème
1. Parcourez les cartes de thème
2. Chaque carte affiche un aperçu des couleurs du thème
3. Cliquez sur un thème pour l'appliquer
4. Le changement est instantané et enregistré automatiquement
5. Un petit point indicateur apparaît sur le thème actif

## Visite guidée d'accueil

Si vous souhaitez revoir la visite guidée de la plateforme, vous pouvez réinitialiser et relancer la visite interactive à tout moment.

### Relancer la visite
1. Faites défiler jusqu'à la section **Onboarding** de l'onglet des paramètres Appearance.
2. Cliquez sur le bouton **Restart guided tour**.
3. Cela réinitialise le statut de votre visite et relance immédiatement la séquence d'accueil interactive menée par John Driver.

## Applications autorisées

Gérez les applications tierces qui ont accès à votre compte.

### Accéder aux applications autorisées
1. Allez dans **Settings** > onglet **Authorized Apps**
2. Ou accédez directement à `trucklinemp.com/user/me/settings?tab=authorized-apps`

### Qu'est-ce qu'une application autorisée ?
Il s'agit d'applications tierces auxquelles vous avez accordé l'accès à votre compte TrucklineMP via OAuth. Cela peut inclure :
- Des configurateurs de camions
- Des outils de gestion d'événements
- Des bots communautaires
- Des tableaux de bord d'analyse

### Vérifier les applications
Pour chaque application autorisée, vous pouvez voir :
- **Application name** - Le nom de l'application tierce
- **Permissions granted** - Ce à quoi l'application peut accéder
- **Date authorized** - La date à laquelle vous avez accordé l'accès

### Révoquer l'accès
1. Trouvez l'application que vous souhaitez révoquer
2. Cliquez sur **Revoke**
3. L'accès de l'application est immédiatement supprimé
4. L'application devra être réautorisée si vous souhaitez l'utiliser à nouveau

### Quand révoquer
- Vous n'utilisez plus l'application
- Vous suspectez un accès non autorisé
- L'application a été compromise
- Vous faites le ménage dans vos anciennes connexions

## Export des données

Demandez une copie des données que TrucklineMP a enregistrées sur vous.

### Accéder à l'export des données
1. Allez dans **Settings** > onglet **Data Export**
2. Ou accédez directement à `trucklinemp.com/user/me/settings?tab=export`

### Ce qui est inclus
Votre export comprend :
- Les informations de profil (nom, identifiant, photo, liens sociaux)
- L'historique de vos adhésions à des VTC
- Les journaux d'activité
- Les données de configuration
- Les messages et sujets du forum
- Les enregistrements de participation aux événements

### Comment faire une demande
1. Cliquez sur **Request Export**
2. Votre export est mis en file d'attente pour traitement
3. Vous recevrez un e-mail lorsqu'il sera prêt
4. Téléchargez le fichier de données depuis le lien contenu dans l'e-mail
5. Le lien de téléchargement expire après un délai limité

### Format des données
- Les exports sont fournis au format JSON
- Toutes les données sont lisibles par machine
- Vous pouvez les importer dans d'autres outils ou les conserver pour vos archives

## Paramètres du forum

Configurez vos préférences de forum.

### Accéder aux paramètres du forum
1. Allez dans **Settings** > onglet **Forum**
2. Ou accédez directement à `trucklinemp.com/user/me/settings?tab=forum`

### Paramètres disponibles
- **Notification preferences** - Contrôlez la façon dont vous recevez les notifications du forum
- **Display options** - Personnalisez l'affichage du contenu du forum
- **Signature settings** - Définissez une signature pour vos messages sur le forum

## Bonnes pratiques

### Thèmes
- Choisissez un thème adapté à vos conditions d'éclairage habituelles
- Les thèmes sombres sont préférables pour les sessions de conduite nocturnes
- Les thèmes clairs sont préférables pour une utilisation en journée

### Applications autorisées
- Vérifiez régulièrement les applications autorisées
- Révoquez les applications que vous n'utilisez plus
- N'autorisez que les applications auxquelles vous faites confiance
- Vérifiez attentivement les permissions avant d'autoriser une application

### Export des données
- Demandez un export avant de supprimer votre compte
- Conservez des sauvegardes de vos données
- Consultez vos données pour comprendre ce qui est stocké

## Dépannage

### « Le thème ne change pas »
- Actualisez la page
- Videz le cache de votre navigateur
- Essayez un autre navigateur

### « Je ne peux pas révoquer une application »
- Assurez-vous d'avoir une connexion internet stable
- Actualisez la page et réessayez
- Contactez le support si le problème persiste

### « Mon export de données n'est pas arrivé »
- Vérifiez votre dossier de spam
- Les exports peuvent prendre quelques minutes à être traités
- Contactez le support si cela prend plus d'une heure
