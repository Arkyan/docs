La page Appearance de votre panneau de gestion d'entreprise contrôle l'apparence de votre page publique. Elle comporte deux parties : l'éditeur de thème et le constructeur de mise en page de l'accueil.

Ouvrez **Appearance** depuis la barre latérale (`/vtc/@handle/manage/appearance`). Nécessite la permission `management.vtc.appearance`. Les propriétaires y ont toujours accès.

## Éditeur de thème

L'éditeur de thème définit les couleurs d'accent, les couleurs d'arrière-plan et les couleurs de texte utilisées sur toute votre page d'entreprise. Les modifications s'affichent en aperçu en direct avant que vous les enregistriez.

Les options de thème avancées sont verrouillées pour la plupart des entreprises. Elles se débloquent pour les entreprises qui détiennent à la fois le statut Vérifié et Partenaire.

Les couleurs doivent réussir des tests de contraste de lisibilité avant de pouvoir être enregistrées, afin que le texte reste lisible sur la page.

## Constructeur de mise en page de l'accueil

Le constructeur de mise en page de l'accueil réorganise les sections affichées sur votre page publique d'entreprise. Vous pouvez ajouter, déplacer, redimensionner ou supprimer des sections telles que l'aperçu, les règles, les membres, les événements, les actualités, la galerie ou le recrutement.

La mise en page n'est disponible que pour les entreprises pouvant accéder à la mise en page personnalisée. Consultez le [Programme VTC Vérifié](/fr/web-docs/vtc-programs/verified/) et le [Programme VTC Partenaire](/fr/web-docs/vtc-programs/partnered/) pour connaître l'éligibilité.
