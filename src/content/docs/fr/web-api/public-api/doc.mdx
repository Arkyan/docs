La spécification complète de l'API publique TrucklineMP, affichée de manière interactive avec Swagger UI. Chaque endpoint, paramètre, et schéma de réponse est généré en direct à partir de la spécification OpenAPI sur [trucklinemp.com/api/v1/openapi.json](https://trucklinemp.com/api/v1/openapi.json).

Utilisez le filtre pour trouver un endpoint, dépliez une section pour voir les paramètres et exemples, et appuyez sur **Try it out** pour envoyer de vraies requêtes. Les endpoints de lecture publique fonctionnent sans clé API ; ajoutez une clé `tlmp_api_...` depuis la [Console développeur](https://trucklinemp.com/developer) pour augmenter vos limites de débit.
